P13 CYBER INCIDENT TRIAGE PLATFORM
===================================

Same project, multiple deployment options:

WINDOWS:
  run.bat

LINUX/VPS:
  ./run.sh

DOCKER:
  docker compose up -d --build

DEFAULT PORT:
  5000

LOCAL:
  http://127.0.0.1:5000

LAN:
  http://YOUR-PC-IP:5000

PUBLIC SERVER:
  http://YOUR-SERVER-IP:5000
  or preferably HTTPS through Nginx/Caddy.

Read DEPLOYMENT_GUIDE.md for full instructions.
